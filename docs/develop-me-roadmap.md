> 开源底座：Dify；按需集成 LangGraph.js、NestJS、企业知识库、Git/CI。  
> 定位：与已有「AI 产研一体化中台」整合，而非重复重建 Dify。项目实际功能应以已合并代码、运行结果和测试为准。

## 2. 产研中台业务闭环

1. 企业文档入库：上传需求文档、工程规范、设计规范，并建立项目/文档级 ACL、版本号和引用。
2. 产品 Agent：读取需求、检索授权文档，输出需求拆分、验收条件、任务依赖和待人工确认事项。
3. UI Agent：根据规范产出页面结构、组件清单与交互约束。
4. 前端/后端 Agent：通过受控 Git / MCP 工具生成或修改代码；记录差异和操作主体。
5. 测试 Agent：在隔离环境运行单元测试、构建与端到端测试；失败时限制重试次数并保留证据。
6. 人工审批：查看需求、Diff、测试报告和成本，再批准创建 PR 或其他被授权动作。
7. 交付与追踪：关联业务任务、代码提交、Trace、审计事件和评测结果；失败任务可恢复。

## 6. 演示、验收与运行

**演示用例：** 导入一份电商订单退款需求和工程规范，产品 Agent 生成任务，UI/前后端 Agent 产出变更，测试 Agent 执行测试；发生一次可控失败并从检查点恢复，人工审批后形成 PR 与报告。

**验收重点：** 越权文档不可检索；未审批不可调用敏感工具；失败可定位/恢复；每个代码产物可追溯来源；至少给出一组真实运行及回归评测结果。

**本仓库现有示例运行：**

```bash
cd examples/enterprise-agent-gateway
npm test
# 根据该目录 README.md 配置 DIFY_API_BASE_URL、DIFY_API_KEY、
# CLIENTS_JSON、PROJECTS_JSON，再运行 npm start。
```
